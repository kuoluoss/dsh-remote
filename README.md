# dsh-remote

DeepSeek Harness（DSH）的远程访问方案：电脑端插件 + 安卓 App。

让手机在任何网络下打开并操作电脑上的 DSH，同时提供手机本地运行 DSH 的合并版本。

## 当前状态

**源码暂不公开。**

2026 年 10 月 20 日，本项目发生一起凭据泄露安全事件：发布流程中的检查工具把真实访问凭据硬编码在自身代码里，并随源码提交到公开仓库。攻击者据此在约 10 小时内访问了本机 DSH。

事件已完整处置：

- 全部泄露凭据已作废并轮换
- 攻击者服务器已封禁
- 本机网络暴露面已加固（SMB 加固、管理共享移除、代理仅本机监听）
- 原有仓库已删除重建，历史记录不再可访问

在整改与复核完成之前，本项目不再公开源码与安装包。
